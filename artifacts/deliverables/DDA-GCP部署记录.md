# DDA GCP 部署记录

2026-10-15 · TOTheMoon / tothemoon-477410 · 部署完成；待独立复核。

## 服务器选择

选择现有美西 silasvps（us-west1-b）。两台各执行 30 次同组 RPC 请求，均成功 30/30。美西各方法中位约 155–161ms，韩国约 163–168ms；美西略快且可用磁盘更多。短测包含 HTTPS 连接开销，不代表长期完整报价速度保证。原始对照见 DDA-GCP测速.json。

## 访问与使用

双击同目录「打开云端DDA.command」，保持打开的终端窗口，再在网页点击「启动采集」。默认 60 分钟后停止，可手动停止。首次需要本机已有 Google Cloud CLI 登录及项目 IAP / SSH 权限。面板连接为 http://127.0.0.1:18787；仅在连接通道开启时可访问。

云端服务只绑定 127.0.0.1:8787，不开放公网端口，不接钱包。面板服务随服务器启动，行情采集不自动启动。关闭本机连接不停止正在运行的会话。

## 隔离与数据

- 当前发布：/opt/dda/releases/20261015-03，/opt/dda/current 指向该目录。
- 数据：/var/lib/dda；独立 dda 用户，目录权限 700。发布与数据分离。
- 服务：dda.service；独立 Node v24.15.0，不替换其他应用环境。
- 内存上限 384MB，V8 堆上限 256MB；部署进程另设 160MB 上限。
- 使用现有虚拟机、免费公共 RPC，无新增云资源或付费数据服务。

## 故障与恢复

首次云端安装依赖时主机失联。恢复后内核日志确认 08:08 UTC 发生全局内存耗尽；被杀进程约 519MB RSS，日志未保留命令行。改成本地组装离线依赖包，云端只解压并受资源上限约束。用户已授权必要时重启，但主机自行恢复，本轮没有执行主机重启。

另修复编译服务经发布链接启动时入口路径比较导致的正常退出；已通过实际链接启动及 HTTP 请求复核。
