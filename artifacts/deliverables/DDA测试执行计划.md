# DDA 测试执行版实施与跟进计划

2026-10-15；授权：用户批准的测试执行计划，工程决定 DDA-010。

| 顺序 | 工作 | 验收依据 |
|---|---|---|
| 1 | Mac 本地隔离目录、全新钱包、网络身份和地址门禁 | 文件权限、错误网络拒绝、真实 RPC 与程序检查 |
| 2 | 单机会状态机、库存预留、签名日志、幂等与恢复 | 确定性场景、真实进程强制中断、余额守恒 |
| 3 | BSC Testnet / Solana Devnet 自有市场适配器 | 免费币到账 → 发行与建池逐笔确认 → 各链兑换 → 双腿对账 |
| 4 | 中文面板与独立启动入口 | 浏览器初始化、运行、停止、恢复、平仓和导出 |
| 5 | 本地待审交付与证据归档 | 自动验证、构建、实际运行代码摘要、PASS / FAIL / NOT RUN |

当前真实链路卡点：全新钱包缺少免费测试币。免费 airdrop 的失败保留为真实证据，不以合成场景替代。资金解决后依次继续初始化，执行小数量兑换并核对浏览器记录，再做受控单腿和平仓。未知签名先恢复查询；不直接重建发送。

尚未独立审查，所有功能只适用于测试网络。云端仍运行原主网只读研究。完成软件构建与确定性测试不代表真实双链验证通过，也不代表套利策略有效。
