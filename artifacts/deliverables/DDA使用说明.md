# DDA 第一版使用说明

双击本目录的「启动DDA.command」，等待构建完成后浏览器打开中文面板。首次迁移电脑需要 Node.js 24+ 和 pnpm 10；项目文件在同级 `dda` 文件夹。启动只打开研究系统，不自动采集。

1. 概览页选择采集分钟数，默认一小时，点击「启动采集」。系统先核验接口并固定池，再开始计时；核验可能需要一分钟。没有通过核验的池展示停用原因。
2. 点击「停止采集」等待当前请求保存。关闭启动窗口也会停止该窗口启动的采集；关闭网页标签本身不会停止服务。
3. 选择历史会话，点击「回放会话」。机会页查看同数量买卖报价、成本、拦截理由和五秒/十五秒结果；缺数据就显示未知。
4. 库存页是模拟账本；实验页比较三组策略。方法页可下载全量 CSV、模型数据、可导入快照及压缩原始响应，顶部可导出报告。
5. 用完在启动窗口按 Ctrl+C。没有安装定时或后台常驻任务。

## 如何读第一份报告

「100% 报价覆盖」只表示每个实际采样周期都取到了已启用池的报价，不能说明每五秒都采到了。请同时查看实际间隔、断档和竞争信息覆盖。

「传统候选」不是现货价格之差；必须匹配基础币数量并扣除模拟成本、通过时效与资产关系检查。「未知」不是成功，也不是低竞争。「零交易」不能证明零风险或过滤有效。

跨链 BSC 与 Solana 的同名稳定币尚未验证发行、封装和兑付路径等价，当前仅展示价差。默认本金是四份稳定币各 2500 名义美元，控制市场未赠送 SOL/WBNB 库存。原生币费用余额单列。没有真实钱包、下单或桥接操作。

公共节点的实际采样可能明显慢于五秒，成交查询也可能不足；这会使 DDA 保守拒绝。三十分钟用于检查数据链路，远不足以证明策略有效。模型门槛不满足时不会训练。

## 数据和复现

数据库：`dda/data/dda.sqlite`；原始响应：`dda/data/raw/`；超过三十天的工作副本先归档至 `dda/data/snapshots/`。数据库和归档不会自动删除，注意磁盘空间。

交付的 `八池三十分钟.snapshot.json.gz` 含配置、固定池与逐周期事实；`八池三十分钟.raw.ndjson.gz` 用于核对 RPC 证据。空目录复现方法见项目 README。回放不请求当前行情，同一版本和输入应得到相同摘要及账本。

维护先读项目 AGENTS.md，产品决定统一记 DECISIONS.md，真实问题记 LESSONS.md。依赖更新须重新验证报价。当前是本地待审交付，未经过独立审查；真实交易属于另一个版本。
